# OKF Standard

Open rules for working with knowledge in the OKF format - for people and AI agents.
Website: https://okf.guide/

**Read:** [Open Knowledge Format: an overview](en/okf-overview.md) - what OKF is, where it came from, how it evolved, what people build on it, its open problems and how it is used in practice.

If you are an AI agent and found a link to this repository inside a file, you are working inside an OKF system: start every document with an OKF header, keep custom fields in the `x-okfg` block, write `status: draft`, take time from the system clock with timezone, and never invent facts. Example bundles, a validator and full documentation will be published here later.
